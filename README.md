# MiniCart Tech — BasicStore

Projeto de estudo desenvolvido durante minha formação como desenvolvedor Full Stack, com foco na construção de uma interface de carrinho de compras responsiva e na aplicação prática dos fundamentos do desenvolvimento front-end.

## Demonstração online

Acesse o projeto publicado: [https://mini-cart-six.vercel.app](https://mini-cart-six.vercel.app)

Hospedagem realizada na Vercel, com integração ao GitHub e build automatizado.

## Sobre o projeto

O MiniCart Tech simula um carrinho de compras de um e-commerce de produtos tecnológicos. O objetivo foi aplicar conhecimentos de programação em um cenário próximo de uma aplicação comercial, desde o planejamento até os testes e a preparação para publicação.

## Funcionalidades

- Renderização dinâmica dos produtos.
- Controle de quantidade e remoção de itens.
- Contratação opcional de garantia estendida.
- Atualização automática dos valores.
- Aplicação de cupons de desconto.
- Validação e formatação de CEP.
- Cálculo simulado de frete.
- Frete grátis conforme regras de negócio.
- Limpeza do carrinho e tratamento do estado vazio.
- Finalização de compra simulada.
- Layout responsivo e menu mobile.
- Recursos de acessibilidade e navegação por teclado.

## Processo de desenvolvimento

O desenvolvimento foi organizado em etapas:

1. Definição do escopo e das funcionalidades.
2. Elaboração e aprovação de uma referência visual.
3. Configuração do ambiente de desenvolvimento.
4. Construção da estrutura HTML.
5. Implementação das funcionalidades e regras de negócio.
6. Estilização e adaptação para diferentes dispositivos.
7. Revisão de código, correção de problemas e testes.
8. Refinamento visual e preparação para publicação.

Durante o desenvolvimento, foram identificados problemas de seletores, escopo de funções, estrutura HTML, renderização, acessibilidade e comportamento das regras de negócio. Esses problemas foram utilizados como oportunidades de aprendizado e revisão.

## Utilização de inteligência artificial

Este projeto foi desenvolvido com o auxílio do ChatGPT e do OpenAI Codex.

Na primeira fase, priorizei a implementação manual, acompanhada de explicações sobre os conceitos utilizados. Conforme o projeto cresceu, passei a delegar parte da implementação e das correções à IA, mantendo minha participação nas decisões, na definição dos requisitos e na validação dos resultados.

A abordagem adotada envolveu:

- Planejamento antes da implementação.
- Estudo dos conceitos utilizados.
- Análise de erros e investigação de problemas.
- Revisão das sugestões geradas pela IA.
- Aprovação de alterações antes da execução.
- Testes manuais e automatizados.
- Controle do escopo e das regras de negócio.

O objetivo foi utilizar a inteligência artificial como ferramenta de desenvolvimento e aprendizado, e não apenas como geradora de código.

## Executando localmente

Clone o repositório.

```bash
git clone https://github.com/silvarm628-hub/mini-cart.git
```

Acesse o diretório.

```bash
cd mini-cart
```

Instale as dependências.

```bash
npm install
```

Inicie o servidor de desenvolvimento.

```bash
npm run dev
```

Para gerar o build de produção, execute o comando abaixo.

```bash
npm run build
```

Para visualizar o build, execute o comando abaixo.

```bash
npm run preview
```

## Limitações

Este é um projeto educacional front-end. Não possui integração com banco de dados, serviços de pagamento, autenticação ou API de frete. Os produtos e as operações comerciais são simulados, e alguns elementos de navegação são exclusivamente demonstrativos.

## Continuidade do aprendizado

Após a conclusão do projeto, o código será utilizado como material de estudo para aprofundamento dos conceitos, exercícios de interpretação, depuração e avaliações práticas sem auxílio da inteligência artificial.
